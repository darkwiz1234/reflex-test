#  Game Hub #

Welcome to **Reflex Hub**, a browser-based mini-game collection built with HTML, CSS, and JavaScript.

## 🎯 Games Included
- **Quick Reflex Game**: Test your reaction speed with visual cues and track your score, streak, and average reaction time.
- **Obstacle Course Game**: A simple Geometry Dash-style runner where you jump over obstacles.

## 🚀 Features
- Interactive UI with buttons for Start, Pause, Reset, and Back to Hub.
- Real-time reaction tracking (last, best, and average times).
- Clean hub menu to switch between games.
- Responsive design with improved visuals.

## 📖 About Reflex Training
Reaction time is the interval between perceiving a stimulus and responding to it. The average human visual reaction time is ~250 ms, but with training, it can be reduced. Reflex games help improve focus, hand-eye coordination, and cognitive speed. This project is a fun way to practice and measure your reflexes.
